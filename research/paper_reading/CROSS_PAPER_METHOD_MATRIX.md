# Thirteen papers locate the MRI method boundary

**Decision.** Existing papers already combine medical/MRI VQA with GRPO, brain-MRI box localization with RL, multi-task medical RL, structured longitudinal T1 verification with DPO, and longitudinal multi-sequence evaluation. The unproved conjunction is **independently validated, acquisition-aware paired-volume change** plus a fair test of whether a task mixture prevents negative transfer beyond SFT, proportional sampling, reward calibration, and active-group controls. This matrix records *author-reported* evidence from the versioned sources; no cited model result has been reproduced locally. Consult the linked [individual audits](./) and [source reconciliation](SOURCE_RECONCILIATION.md) for methods and page checks.

**Reading rule.** The papers' metrics are not exchangeable: 2D option accuracy, frame V-Score, 3D CT Dice, report factual pass and FreeSurfer-referenced direction have different targets and units. Table values are **reported results** with the stated source scope. The local Dallas result is only eight checksum-matched volumes from two subjects with CPU ingestion/rendering; model inference, task reward validation and RL training are `NOT_RUN` ([execution status](../../results/EXECUTION_STATUS.md)).
