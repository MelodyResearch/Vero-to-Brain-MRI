## 1. 正仿射不变性

- 当 `epsilon=0` 时,`(a·v+b − (a·m+b)) / (a·σ)` 在数学上等于 `(v−m)/σ`(a>0)。所以 `raw` 与 `affine`(2x+5)的优势在数学上相同,实现上也成立。
- **浮点上不是逐位相同。** 2x+5 会引入舍入,不应用 `==` 比较,而应当用容差断言。文件内没有任何此类检查或测试。
- **`epsilon>0` 时不再不变。** 分母是 `σ+ε`,affine 后变成 `2σ+ε`。affine 优势是 `2d/(2σ+ε)`,大于 `d/(σ+ε)`。
  - 不变性只在 ε=0 成立。
  - `main()` 和 `replay_groups` 默认 ε=0,所以 ε 的影响从未被展示。
- **`*_format` 方案不满足仿射不变性。** `0.8·(2x+5)+0.2·f` 改变了内容与格式的相对权重,`affine_format` 与 `raw_format` 的差异来自混合权重,不是来自仿射变换。如果有人拿它们对比"仿射不变",会得出错误结论。
- **总体标准差(ddof=0)。** 很多实现用 `torch.std` 的无偏估计(ddof=1)。组大小固定时只差常数 √(n/(n−1)),但与 ε 相互作用,且组大小不同时不可比。我没有核实 MedGRPO/Vero 实际用哪个。

## 2. ε 与非线性 logistic

- **ε 的软过滤效应。** ε=0 时,极小方差的组也会被放大到单位方差。ε>0 时,极小方差的组优势趋近 0,相当于软过滤。两者行为差别很大,但没有任何 ε 扫描。
- **logistic 是严格单调的非线性变换,不是仿射。**
  - 它保序,但改变间距,所以 `spatial-graded-*` 组的优势会变。
  - **二值组(categorical)上不会有任何差异。** 只有两个取值的组,标准化后只取决于比例,任何严格单调映射都给出相同优势。这意味着 fixture 里 categorical 组无法检验 logistic。
- **饱和会制造平局。**
  - `z=3(x−p50)/iqr` 足够大或足够小时,logistic 在浮点下取到 1.0 或下溢到 0。
  - 这会把本来不同的值变成平局,甚至让整组变成"全平局"。
  - iqr 很小时更容易发生。fixture 的 iqr 为 0.5 和 1,所以没有触发。
- **校准粒度有问题。** p50/iqr 在这里是**每组**传入的。如果按"训练集推导的任务级常数"理解,同一任务的所有组应当共用同一组 (p50, iqr),但代码没有校验。每组各自校准会变成组内归一化,与 MedGRPO 的意图不符(此点依赖未核实的记忆)。

## 3. 全平局过滤

- 判据是 `variance == 0` 的精确浮点比较,这是一个**具体 bug**。
  - 例如三个 0.1 求和后除以 3,均值可能是 0.10000000000000002,方差约 1e-34 但不为 0。
  - 该组会被判为 `active=True`,优势被放大成约 ±1 的垃圾信号。
  - 反过来,`2x+5` 的舍入也可能制造或消除平局。
  - 建议改用 `max(values) == min(values)`,或加相对容差。
- **过滤作用在混合后的奖励上。** 内容全平局但格式有差异的组仍然 active,见下一节。
- 缺少"近平局"阈值,没有 ε 与过滤交互的说明。

## 4. 仅格式的梯度

- fixture 中 `cat-all-wrong-format-varies` 的内容全是 0、格式为 `[1,0,1,0]`。
  - `raw` 方案下该组 inactive。
  - `raw_format`、`affine_format`、`logistic_format` 方案下该组 **active**,优势约为 ±1。
  - 即梯度完全来自格式奖励。
- **标准化会放大格式信号。** 格式只占 0.2 权重,但标准化后优势尺度与内容信号相同,0.2 的权重在内容无方差的组里不起作用。
- **summary 没有标出这一点。** `active_groups` 把"内容驱动的 active"和"仅格式驱动的 active"混在一起。缺少这些指标:
  - `content_active`
  - `format_only_active`
  - 格式优势与内容优势的相关性

## 5. 任务有效份额

- `active_share` 按**组数**计算,不是按样本数、token 数或梯度质量。
  - 组大小不同时偏差明显。
  - token 级损失(按长度加权)与序列级损失(GSPO 风格)下,份额含义不同。
  - 文件没有响应长度、裁剪比例、重要性比的信息。
- 标准化后每个 active 组的优势方差都是 1,但 L1 质量和正负不对称不同。比如 4 个里只有 1 个成功,与 2 个成功的组,梯度结构不同。
- `nominal_share` 在各方案间完全重复。`active_share` 是唯一有信息的指标,但只反映过滤结果。

## 6. 能否称为 MedGRPO 复现

**不能。** 它是"奖励变换的离线诊断回放",原因如下:

- 没有策略模型、没有 rollout 生成。
- 没有 KL 项、裁剪、优化器、overlong 惩罚(docstring 已声明)。
- 没有 GSPO 的序列级比率,也没有 MT-GRPO 类的多任务动态加权(此点依赖记忆)。
- 奖励是手写玩具值;真实任务奖励函数(`mri_rl.core.reward`)我没有审阅。
- 当前措辞"诊断/replay"是恰当的,如果要写成"MedGRPO reproduction"则是过度声称。docstring 里"fixtures must never be reported as VLM results"的声明是对的,应在输出里保持。

## 7. 其他具体问题

- `constant_output_probe` 的 fixture 是 3 个 T1 加 1 个 FLAIR,只能说明类先验可得到的奖励。它的结论依赖未审阅的 `reward`,不能外推。
- 缺失键(如 `group["id"]`)直接抛 `KeyError`,且校验顺序在取值之后。这只是小问题。
- 仿射控制只有一个固定的 `2x+5`,没有负尺度对照。负尺度应当翻转优势符号。

## 8. 缺失的对照实验

1. 仿射不变性的容差断言,覆盖 ε=0,以及 ε>0 时不变性被破坏的反例。
2. ε 扫描(0、1e-8、1e-4 等)和 ddof=0/1 对照。
3. 近平局容差,以及构造的浮点平局用例(如三个 0.1)。
4. 负尺度仿射对照。
5. logistic 饱和用例。
6. 二值组上 logistic 无差异的断言。
7. 同一任务共用 (p50, iqr) 的校验。
8. 内容 active 与仅格式 active 的拆分统计。
9. 去掉 std 归一化的对照(Dr.GRPO 风格),看低方差组的放大效应。
10. 随机格式对照(打乱格式分),估计格式噪声对梯度的贡献。
11. 按样本数和 token 数加权的份额。
12. 组大小不一的用例。
