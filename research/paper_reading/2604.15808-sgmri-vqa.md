# SGMRI-VQA — primary-source audit

## Verified metadata and access

**Identity and scope.** `arXiv:2604.15808v1`, submitted 17 April 2026: *Beyond a Single Frame: Multi-Frame Spatially Grounded Reasoning Across Volumetric MRI*, Lama Moukheiber et al. This is chiefly a **benchmark/data-construction paper with an SFT baseline**, not an RL or native 3D-encoder result. The [full HTML paper](https://arxiv.org/html/2604.15808v1) was read through Methods, Results, Appendix, and limitations; the [official code repository](https://github.com/lamawmouk/SGMRI-VQA) was checked. The web reader rejected the PDF on size, but an independent [source reconciliation](SOURCE_RECONCILIATION.md) downloaded the [exact v1 PDF](https://arxiv.org/pdf/2604.15808v1) and verified the key page pointers below. The repository README uses a shorter/different title than the arXiv record; this is a **SOURCE_MISMATCH in title wording**, not in paper identity.

## Layer 1 — Research process

The research gap is cross-slice *finding localization* in MRI VQA. Earlier VQA sets are mostly single 2D images; 3D segmentation models do not offer the same question-answering interface. The authors chose expert-annotated fastMRI+ because it supplies slice-specific pathology boxes, then converted HDF5 volumes to ordered PNG frames with orientation correction and min-max normalization. The retained set has 1,970 volumes (996 brain, 974 knee), 50,672 slices, and 23,724 boxes, per §3.1.1. Brain inputs include axial FLAIR/T1; knee uses sagittal PD fat-suppressed images. This is a *multi-frame 2D input representation*, not direct voxel-native 3D processing.

They generated image- and volume-level QA with GPT-4o given clean images, box overlays, structured labels/coordinates, and clinical context (§3.2); a physician specified templates and reviewed outputs (§3.3). The design makes frame index plus in-frame `[x,y,w,h]` the verifiable target. The paper's 41,307 final items split into 32,142 image-level and 9,165 volume-level; 32,014 train and 9,293 test (Table 2, PDF p. 7). The scope of manual review is internally ambiguous in §3.3.1, PDF p. 6: it says the physician reviews all QA pairs, then specifies full coverage for 222 brain and 155 knee test volumes but iterative review of **over 300 training volumes**. Exhaustive training-set manual review is therefore **NOT_VERIFIED**.

The model choice is Qwen3-VL-8B, a general VLM that accepts multiple images. They chose **supervised fine-tuning** on the generated answers and box supervision, freezing the vision encoder and projector while updating the language backbone for two epochs on eight H100 GPUs (§4.1). There is no GRPO/GSPO/DPO objective here. Plausible alternatives—native 3D encoders, segmentation masks, or RL with box reward—were not tested. Native 3D input could improve inter-slice consistency but costs volume memory; mask reward would test actual volumetric extent, while boxes cannot establish it. Their conclusion proposes GRPO only as future work (§5).

## Layer 2 — Evidence audit

| Claim | Direct evidence | Judgment |
|---|---|---|
| Strong zero-shot VLMs struggle with pixel grounding | Tables 3–4, PDF p. 9: best zero-shot V-Score is 5.95 image-level and 1.83 volume-level, while several approaches are near zero. | **Direct Evidence**, within their parser, coordinate and box metric. |
| SFT improves benchmark performance | Table 3, PDF p. 9, image average: fine-tuned Qwen3-VL 59.45 vs its starting Qwen3-VL 41.66. Table 4, PDF p. 9, volume average: 49.23 vs 33.18. Image V-Score 15.51 vs 3.11; volume V-Score 5.97 vs 0.16. | **Direct Evidence** for this supervised training recipe on this test split. |
| Clinically reliable spatial localization | Even SFT volume V-Score is 5.97 (Table 4, PDF p. 9). | **Not Established**. The reported average gain does not imply usable localization. |
| Better reasoning traces / 3D understanding | AR-Score uses GPT-4o-mini, BERTScore, BLEU, ROUGE; for localization it strips boxes and frame references (§4.1). Input is frame sequence. | **Conditional Evidence** for answer-text agreement; native 3D geometry and reasoning validity remain **NOT_VERIFIED**. |

Comparability is limited: all zero-shot models share prompts, but SFT sees 32,014 domain QA items that zero-shot competitors do not; those comparisons isolate *supervision plus data*, not architecture. Proprietary models and differently sized open models are not matched for parameters or training provenance. No matched same-data SFT-vs-RL, equal-data caption-only, box-only, or independent-seed SFT ablation is reported in §§4–5. The paper specifies volumes as the split unit; independent **patient** identity across scans is **NOT_VERIFIED** from the paper alone. Explicit clinical progression or longitudinal repeat-scan testing is absent. Scores report boxes on frames, not 3D Dice. The official repository says source MRI and generated benchmark data are not included there; reproducibility of data linkage needs a separate audit.

## Layer 3 — Next experiment

**Question.** Does a frame-indexed reward add true cross-slice grounding beyond SFT on the same box data? **Hypothesis.** With identical Qwen3-VL initialization, exposure, compute, and patient-disjoint split, SFT plus verified frame/box RL improves *held-out-volume* localization without reducing detection and caption performance. Start with a cheaper control: re-evaluate the SFT checkpoint against a frame-agnostic box scorer and a frame-shuffled input. If performance survives frame shuffling, cross-slice understanding is falsified before training.

Use fastMRI+ with verified subject keys and licensed images/boxes. Compare starting model, released SFT, and equal-data SFT control; only then test RL. Primary metric: **per-volume** mean frame-aware box IoU/F1, with patient-level bootstrap if patients have multiple volumes; report brain and knee separately. Ablate frame index, neighboring slices, box reward, answer reward, and SFT-only. GO if an RL arm improves held-out patient/volume grounding beyond SFT and shuffle controls without caption regression; REFORMULATE if gains are parser or format effects; KILL this reward if shuffled frames score similarly or localization remains near zero. No clinical diagnosis claim follows from this result.

## Independent novelty and MRI transfer

**Exact novelty:** benchmark construction/evaluation with ordered MRI frames, physician-aligned generated QA, and frame-indexed 2D box grounding. **Inherited:** fastMRI+ annotations, Qwen3-VL architecture, GPT-4o generation, SFT, Hungarian box matching. **Necessary technical difference:** crossing frame identity with box coordinates and question hierarchy. **Remaining space:** physically calibrated voxel coordinates, 3D masks, cross-sequence registration, genuine longitudinal change, and reward validity. A Vero-style project that merely adds box rewards on this benchmark would largely reproduce its open future-work suggestion. A minimally novel MRI result would show a matched-data, matched-compute improvement on **registered 3D/longitudinal evidence** and preservation of other tasks, with pixel-only and SFT controls.

**Project implication:** use SGMRI-VQA as a grounding prior-art and perhaps spatial task source only after data licensing and subject lineage checks; keep its 2D V-Score separate from any future 3D Dice. No claimed RL outcome transfers from this paper.
