# MedVol-R1 — reward-driven 2D anchors for 3D CT segmentation

## Verified metadata and access

Zichun Wang et al., *MedVol-R1: Reward-Driven Evidence Grounding for Volumetric Reasoning Segmentation*, [arXiv:2605.26621v1](https://arxiv.org/pdf/2605.26621), 26 May 2026. Full 10-page PDF checked; [code](https://github.com/AdvancingEther/MedVol-R1) is linked but not run. Venue acceptance is **NOT_VERIFIED** from the paper; repository title claims provisional MICCAI 2026 acceptance. Scope is single-visit CT segmentation; there is no repeated MRI or temporal task.

## Layer 1 — Research process

**Task.** Given a CT volume and a free-form implicit query, output a voxel mask. The VLM receives 64 uniformly sampled 256×256 axial slices, predicts one slice index and 2D boxes, then frozen MedSAM2 propagates the anchor into a 3D mask (Fig. 1; Secs. 2.1, 2.3). Thus its evidence selector is a 2D multi-slice model plus a separate propagation model, not a native 3D visual encoder.

**Training and objective.** SFT learns a mask-derived Top-K visible slice and component boxes. Qwen3-VL-4B with LoRA rank 128 receives one SFT epoch; GRPO then runs three epochs, group size four and β=0.01 on A6000 GPUs (Secs. 2.4–2.5, 3.1). Eq. 2 normalizes rewards within prompt groups. Equal-weight reward terms are format validity; foreground area of selected slice divided by maximum area; Hungarian-matched 2D box IoU; and MedSAM2 mask Dice within ±Δ slices, Δ=5 (Secs. 2.5, Eqs. 4–8). This last term is local 3D supervision from the reference mask, not longitudinal coherence.

## Layer 2 — Evidence audit

**Direct Evidence, reported performance.** Table 1 (PDF p. 7) reports SFT→SFT+GRPO Dice 85.52→89.86 on AbdomenCT-1K, 83.23→85.43 on CT-ORG, and 36.21→45.46 on KiTS23. Table 2 (PDF p. 7) removes each reward on AbdomenCT-1K; dropping box IoU gives the largest decrement (89.86→87.58). RL without SFT is marked non-convergent. **Conditional Evidence:** The paraphrased KiTS23 test queries differ from the original benchmark phrasing (Sec. 3.1, PDF p. 6), so cross-method comparison depends on exactly how all baselines were queried. The text provides no confidence intervals or multi-seed variation in these tables, and does not establish patient-level separation across source cohorts.

**Not Established / method audit.** The spatial IoU and local Dice reward require a training reference segmentation mask. That is defensible for labeled CT training but unavailable for most public longitudinal brain-MRI data. The paper says MedSAM2 is prompted with “matched boxes” in the Dice reward (Sec. 2.5, PDF p. 5); the exact handling of predicted versus reference boxes should be checked in code before porting, because prompting with a reference box would leak target location into the reward. The reported result supports a 2D-anchor-plus-propagator pipeline for CT segmentation, not an autonomous 3D spatial reasoning claim. The authors explicitly reserve MRI extension for future work (Conclusion, PDF p. 8).

**Novelty for our project.** GRPO with format, slice-selection, 2D IoU and cross-slice Dice terms is prior art. A new brain-MRI claim must address verified repeated visits, anatomical registration and protocol drift, and must distinguish 2D frame IoU from volumetric Dice.

## Layer 3 — Next experiment

With a small *training-only* brain-MRI set that has QC'd masks, freeze MedSAM2 and compare: SFT-only anchor policy; SFT+GRPO with format/2D IoU; and SFT+GRPO adding local Dice. Fix equal image budgets and subject-disjoint splits. Inspect whether predicted boxes alone, without reference boxes at propagation time, improve held-out full-volume Dice and lesion/region detection. A random or oracle-key-slice control quantifies what the selector contributes. If a simple supervised selector plus frozen propagator matches RL on held-out subjects, the RL advantage is falsified. For temporal claims add genuinely repeated scans and test paired change separately; a single-visit segmentation score cannot support it.

**Decision:** REFORMULATE for MRI. Strong design precedent for verifiable spatial rewards when masks exist; unsuitable as direct evidence for longitudinal reasoning or mask-free rewards.

## Independent novelty and MRI transfer

Spatial GRPO is inherited from this work. A new MRI contribution must add and validate a real temporal target, robust geometry, and patient-disjoint change evaluation beyond the single-visit CT anchor mechanism.

## Missing evidence and uncertainties

No code run, mask provenance audit, patient-key audit, multi-seed variance or MRI transfer experiment was verified.
