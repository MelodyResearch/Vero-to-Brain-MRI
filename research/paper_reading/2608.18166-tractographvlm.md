# TractoGraphVLM — primary-source audit

## Verified metadata and access

`arXiv:2608.18166v1`, submitted 16 August 2026, *TractoGraphVLM: A Unified Vision-Language Framework for White Matter Tractography*, Gurucharan Marthi Krishna Kumar, Janine Dale Mendola, Amir Shmuel; the arXiv record states acceptance as an ECCV 2026 AI4M3D workshop spotlight. Read [full PDF, 27 pages](https://arxiv.org/pdf/2608.18166), [HTML including supplement](https://arxiv.org/html/2608.18166v1), and confirmed the [official code repository](https://github.com/AS-Lab/Marthi-et-al-2026-TractoGraphVLM-Unified-Vision-Language-White-Matter-Tractography). PDF page references below are **one-based** (web PDF P7 = page 8). This is a graph-representation/multi-task **supervised** VLM paper for *diffusion tractography*, not longitudinal T1/FLAIR MRI or RL.

## Layer 1 — Research process

The problem is that streamline bundles carry 3D direction and topology poorly represented by a rasterized occupancy grid, while existing tractography methods classify or filter bundles without flexible text (§1, PDF pp. 2–3). The documented gap is a shared representation supporting classification, text retrieval, captions, and VQA, with a controlled encoder comparison. HCP-YA provides 1,113 diffusion MRI subjects and 78 atlas bundles; subject-disjoint 70/15/15 train/validation/test is reported. HCP Aging (725 subjects, different age/protocol) is external zero-shot evaluation (§2.1, PDF pp. 3–4). Bundles are produced with iFOD2, anatomically constrained tractography, and RecoBundles; therefore the model studies **derived tractograms**, not raw MRI signal.

They sample 32 nodes per streamline, each carrying 3D position plus tangent orientation, and connect sequential and nearby points (§2.2, Fig. 1, PDF pp. 4–5). A GPS graph encoder outputs a 256-D bundle embedding; symmetric InfoNCE aligns it to frozen BiomedBERT, while projected visual prefixes condition a BioGPT decoder (§2.4, Fig. 2, PDF pp. 5–6). This choice lets all four readouts share one feature and tests a mechanism (orientation preserved) against graph, point, and voxel encoders. The loss and training are contrastive-plus-generative supervised; SFT-like optimization, **not GRPO/GSPO**. Captions and VQA are generated from geometry and a 78-bundle anatomical knowledge base, then paraphrased (§2.3, supplement S1); the authors explicitly acknowledge that output content is largely determined by bundle identity. A plausible alternative is classifier-plus-knowledge-base lookup (tested in S3); independent expert-written subject-specific descriptions would test whether language understanding extends beyond atlas facts but require more annotation.

Table 8 (PDF p. 14) reports frozen-feature probes: hemisphere 99.4±0.2 vs supervised classifier 96.3±1.8, family 94.1±0.5 vs 90.8±2.6. The attributes were absent as *classification labels* but present in caption text, so the result supports richer **supervision**, not spontaneous discovery. The paper reports paired-seed Wilcoxon tests at p<0.05 for selected comparisons, uncorrected over many metrics (Table 2/6 captions). Data augmentation, architecture parameter counts and seeds are described in supplement S4–S5, but exact equivalence of model capacity across all encoder variants is not guaranteed; GPS has 1.908M visual parameters, other encoders vary (S4 Table S9/S10). Generative references and predictions draw on the same knowledge-base/template pipeline; BLEU/ROUGE are relative consistency metrics, **not independent clinical-text validity** (§3 and Discussion). External HCP-Aging shift conflates age, resolution, and protocol. The reported subject split does not establish independent tractography atlas construction across cohorts; **NOT_VERIFIED**.

## Layer 3 — Next experiment

**Question:** Does the graph VLM truly use geometry beyond atlas identity? **Hypothesis:** orientation-aware bundle input improves answer accuracy for *subject-specific* geometric facts that cannot be looked up from a bundle name. Smallest decisive test: fix the trained model and compare correct graph, within-bundle permuted orientation, and identity-only/oracle-label lookup on held-out subjects for manually checked subject-specific trajectory/extent questions. Ground truth should derive from independent geometric measurement and clinician QA on the actual tractogram, not the training knowledge-base template. Use subject as inference unit; primary metric is accuracy on geometry-dependent items, with paired subject bootstrap. Ablate orientation, streamline shape, and label exposure. GO if geometry-sensitive answers exceed lookup and collapse under orientation corruption; REFORMULATE if gains only reflect identity; KILL a new language-grounding claim if oracle lookup matches the model on independent prose. This control precedes any costly retraining.

## Independent novelty and MRI transfer

**Exact novelty:** application of shared graph-text representation and four-task readout to tractography, with controlled visual-encoder comparison. **Inherited:** GPS, BiomedBERT, BioGPT, InfoNCE, atlas bundle segmentation, template QA. **Necessary difference:** streamline position+tangent graph tied to text and a single multi-task checkpoint. **Remaining gap:** subject-specific biological/clinical validity of generated text and longitudinal change. The result does not make graph encoding appropriate for scalar T1/FLAIR intensities; transfer is plausible only if our project has diffusion tractograms with trustworthy streamlines and corresponding text. A project merely adding tractography as another MRI task would be an application. A genuinely new result would require verified cross-visit tract change reasoning beyond identity lookup and scan-protocol controls.

## Missing evidence and uncertainties

No RL training or reward ablation, no T1/FLAIR longitudinal experiment, no independent clinical prose reference. The official repository is accessible, but an executable reproduction and pinned commit of its code were **NOT_VERIFIED** in this audit. The paper itself cautions that the knowledge-base entries were not reverified against subject-level dissection (supplement S2).

Potential Method: geometry-grounded graph-text QA, not GRPO by default. Minimal Experiment: frozen model, true graph, permuted tangents and oracle identity lookup on held-out subjects with independent numeric geometry labels. Strongest Baselines: oracle bundle-name lookup and supervised geometric predictor. Evaluation: subject-clustered accuracy/calibration on facts not in templates.
