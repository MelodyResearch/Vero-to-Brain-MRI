# Fixed-case 256-token unfinished reasoning control — frozen before Adam60 readout

Tag: `EXPLORATORY_DIAGNOSTIC`. Status: `PROPOSED`, `NOT_RUN`.

Question: Does shortening unproductive free reasoning raise strict greedy correctness on a fixed subset of existing MRI sequence questions, without changing trained weights or grading? The control changes **only one inference prompt instruction**: ask for a single concise `<think>` sentence before the usual `<answer>\\boxed{...}</answer>`; the image, task question, system template apart from this addition, greedy temperature, 256-token cap, tokenizer, adapter and strict parser remain fixed. Run only after the original SFT queue is naturally idle, serially using an already trained checkpoint. The original 256-token frozen evaluation is the immutable comparator; any new score is tagged inference-configuration effect, not training improvement.

Fixed subset: the union of sequence questions whose saved Adam52 or Adam56 greedy outputs ended with `finish_reason=length` at 256 tokens. There are nine unique questions: five are invalid in both checkpoints, two only in Adam52, two only in Adam56. The sorted union's identities stay in ignored `local_data/inference_control_v1/fixed9_PRIVATE.json` in the adaptive worktree, sealed before Adam60 evaluation (manifest SHA-256 `ece17d93ebaeaf612d84bba07cffd053daf0afb015edf21e575dfa4624c4d276`). The sorted-union fingerprint is `71bd3d597b4f67747760afc3520f57be098f7c4be4f19f22a4bdbf6ab74526db`; the five-case intersection has SHA-256 of sorted IDs `d421d1dd9796ebb4a5bb39a27c03d9075097c56a9c4015683886c8d1c74976d9`. No case is selected using Adam60 results.

For every fixed item, compare original 256-token greedy output against concise-prompt output for strict correctness, valid format, FLAIR/T1 class, generated tokens, finish reason and wall time. Retain the same Vero tags and boxed answer. Report the paired change in strict correct count separately from merely reducing invalid responses. Compare no candidate scores across prompt variants unless all candidate contexts are re-evaluated under the same changed prompt. If invalid falls but strict correct does not rise, stop treating generation-length repair as an accuracy remedy. No new GSPO follows from format-only improvement.

Source CPU check (no model load): Adam52 and Adam56 each have 7/24 length-terminated, unclosed-think, no-answer sequence outputs; the invalid sets overlap in five, so they are not simply the same seven cases. Their mean generated sequence tokens are 115.38 and 96.58 respectively; all length cases use the full 256. This is an exploratory repeatedly observed development subset, not an independent estimate of population accuracy. Sealed final100 stays untouched.
