# Root-cause hypotheses for the Vero-to-MRI transfer

Status: exploratory engineering diagnosis, 2026-10-15. The earlier eight-patient set has influenced method decisions and is no longer a prospective test. New interventions are selected only with train/internal-development patients.

| Rank | Hypothesis and motivating observation | Competing explanation | Cheapest discriminating experiment and expected result | Falsification / recipe effect | Execution status |
| --- | --- | --- | --- | --- | --- |
| 1 | **H1: Prompt and reward contract suppress otherwise correct answers.** The original 28-step SFT internal-dev inference used no system instruction, unlike its training examples; 48/54 responses contained a box but 0/54 had the strict wrappers. All earlier strict RL groups had zero reward. | The model cannot learn the format even when prompted consistently, or the reward parser rejects outputs that the official parser accepts. | The same SFT28 adapter on the 54 development questions changed from 0/54 to **54/54 strict-valid** when the exact SFT system message was restored; its matched 4-bit starting adapter remained 0/54. A CPU golden case also exposed nested-box extraction drift and was corrected. | The missing system instruction is a verified cause of the *first SFT28 probe's* zero-format result. It does not explain all earlier SFT4 RL zero-reward groups. Correcting the prompt interface preserves intended reward behavior; loosening the parser is a separate ablation. | `INFERENCE_COMPLETED` and independently reviewed by isolated Codex agent; `enable_thinking=False` was byte-identical to omitted in pinned template. Claude review `NOT_VERIFIED` due prior sharing rejection. |
| 2 | **H2: Too few informative rollout groups.** Three direct-format arms each had 0/8 active groups at group size 2. | Reward parser makes every outcome zero, so increasing group size cannot help. | On fixed train prompts, decompose semantic correctness/format/length then compare sequential group sizes 2, 4 and at most 8 under one preset decoder. Count unique answers, reward variance and token cost. | If no valid or correct outputs appear at n=8, larger groups are not an adequate remedy. Larger groups change the local approximation toward official n=8 but cannot be attributed to task balance. | `PLANNED`, conditional on H1 output audit. |
| 3 | **H3: Weak MRI visual dependence and class-prior shortcuts.** Frozen base/Vero changed answers on only 2/16 and 4/16 swapped-image controls; training-majority macro exceeded frozen models. | Chosen swapped items were visually ambiguous, or parser failures hide changes. | On 24 balanced internal-dev sequence questions, SFT28 answered 15/24 with image, 12/24 without image (all FLAIR), and changed appropriately on only 6/24 same-patient/slice opposite-sequence swaps. | This supports **partial but weak** sequence pixel dependence; it does not validate tumor routes. Strong appropriate gains on a larger prospective cohort would weaken shortcut concern. Does not change Vero recipe. | `INFERENCE_COMPLETED` for paired sequence/no-image controls; tumor level-matched controls still `NOT_RUN`. |
| 4 | **H4: Frozen vision and 4-bit rank-4 language LoRA limit MRI adaptation.** Current MLX SFT/RL adapts language modules and leaves vision encoder frozen. | Tasks or labels are weak; a stronger visual adapter would not help. | First verify trainable modules and image-conditioned gradient path. Then compare a feasible same-data supervised visual baseline/projector adaptation under declared parameter budget, using development patients. | If trainable vision/projector control adds no image dependence, frozen vision alone is insufficient as explanation. Changing trainable modules is a declared implementation/control difference from Vero. | `AUDIT_IN_PROGRESS`; no controlled vision-adaptation result. |
| 5 | **H5: Training duration and task quality are inadequate.** Four-step SFT barely changed heldout scores; 28-step SFT has now completed 28 optimizer updates across 28 train patients. Three tumor routes derive from one mask family. | Prompt mismatch or optimizer failure is primary, irrespective of duration. | Evaluate 28-step vs identical quantized start on matched internal dev; inspect loss, gradient, wrappers, correctness and pixel dependence. Audit mask-derived task redundancy and slice answerability. | Format but no visual gain refutes “more format training alone” as a sufficient recovery. Task redesign is required if image-free controls match real-image answers. | `TRAINING_COMPLETED` for SFT28; internal-dev comparison in progress. |

**Decision order.** H1 is cheapest and blocks strict reward learning. H2 is measured after valid parsing is established. H3 and task answerability are independent scientific gates before a larger RL comparison. H4 is an optimization/representation control, not evidence that Vero's multi-task method fails. H5 is evaluated with a fixed development split; the explored eight-patient set cannot select the intervention.
