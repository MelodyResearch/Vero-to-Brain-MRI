# Independent statistical, RL, and novelty review (2026-10-15)

Scope: design audit only. No MRI data, model inference, weight update, or empirical transfer result was inspected here. Claims below are recommendations or prior-art boundaries, not findings from this project.

## Prior-art boundary

- [Vero v3](https://arxiv.org/html/2604.04917v3) already reports that single-category visual RL can transfer poorly, while uniform category mixing, task-routed rewards, and open-ended prompts help broad capability. Its [released implementation](https://github.com/zlab-princeton/vero) includes newer June 2026 checkpoints and datasets, but the default experiment uses Vero-600K. Thus a MRI transfer matrix is potentially useful empirical science, not by itself a new algorithm.
- [Med-R1](https://arxiv.org/html/2503.13939) already studies medical VLM RL with cross-modality and cross-question-type generalization. Explicitly compare its design and metrics before calling cross-task medical RL new.
- [MedGRPO](https://arxiv.org/html/2512.06581) already addresses heterogeneous medical rewards via dataset-specific median/percentile logistic transforms and a medical caption judge. Mere reward normalization or multi-dataset GRPO is prior art.
- [BrReMark](https://arxiv.org/abs/2606.25894) already combines brain MRI localization and diagnosis rewards; [LoV3D](https://arxiv.org/abs/2603.12071) already links longitudinal 3D MRI to verifiable anatomy assessments; [MedVol-R1](https://arxiv.org/abs/2605.26621) already uses verifiable volumetric grounding. MRI + RL + IoU + quantitative anatomy is insufficient novelty.
- A possible publishable claim is a *measured failure of uniform balancing under heterogeneous MRI tasks* with a new operation that beats Vero and MedGRPO controls on independent patients. Until that result exists, label proposed methods hypotheses.

## Minimum falsification ladder

1. **Feasibility and leakage gate.** Build subject/study/series lineage for real images, QA, boxes, and any derived measures. Deduplicate patients and near-duplicate images across train/validation/test and across datasets. Audit question answerability from actual rendered evidence with a blinded sample. If longitudinal images are not legitimately available, the longitudinal hypothesis is untestable; report `DATA_BLOCKED`, not an inferred result from single-frame QA.
2. **Paired pretrained transfer test.** Same Qwen3-VL-8B-Instruct base and matching Vero-Qwen3I-8B (not Qwen3.5-9B), identical renderings, prompts, visual token cap, decoding, answer parser, and held-out patients. Evaluate grounding and at least one different verifiable MRI category. This tests model transfer only; it does not test the value of task-balanced MRI RL.
3. **Smallest RL falsification experiment.** Start all arms from one frozen MRI-capable checkpoint; use two well-supported task families with subject-disjoint held-out samples, e.g., grounding and independently verified anatomy. Train `G-only`, `A-only`, `proportional G+A`, and `uniform G+A`, each at the *same total number of rollout groups/visual tokens and optimizer updates*. Evaluate both tasks at fixed checkpoints. If single-task off-diagonal changes are zero/positive within uncertainty, H1 is not supported. If uniform does not beat proportional on macro score without worsening worst-task score, H2 is not supported. Add a third true longitudinal category only after independent same-patient repeat-volume labels and held-out patients are available; never use BrainTRACE test cases to tune.
4. **Reward hypothesis.** Hold sampler, data, and rollouts fixed; compare raw task reward, a common bounded reward with predeclared calibration, and an implementation of MedGRPO's median-centered transform. If a proposed MRI calibration shows no gain against MedGRPO on patient-held-out metrics and stability, H3 does not justify a new method.

## Matched-compute transfer matrix

Pre-register rows `base`, `domain SFT`, each single-task RL arm, size-proportional mixture, uniform mixture, uniform + task-routed verifier (if distinct), and uniform + MedGRPO normalization. Include only task columns with actual reliable test labels. In each cell store estimate, patient-cluster interval, number of patients/studies/QA pairs, inference cost, and state (`INFERENCE_COMPLETED`, `NOT_RUN`, etc.). Add an external-generalization column only when source overlap is excluded.

For the RL arms, hold fixed initial weights and SFT history; eligible source pool; patient split; image selection and image token budget; answer format; optimizer and learning-rate schedule; KL/clip/entropy settings; rollout group size and sampling temperature; total sampled trajectories, generated tokens, effective optimizer steps, and GPU-hours. Log all four, because matching steps alone can conceal different rollout costs. Mixtures may see the same examples more often when a category is small; quantify patient and question exposure and include a matched-exposure sensitivity analysis. Prefer 3 training seeds if resources allow; with one seed call the outcome preliminary and avoid a robust negative-transfer claim. Fix checkpoint selection using validation patients before test scoring; no cherry-picking the best test step.

Define `T_ij = metric(checkpoint trained on i, test category j) - metric(base, category j)`; include all off-diagonal `T_ij`, not only successful cells. Negative transfer means a predeclared clinically/technically meaningful drop with uncertainty excluding zero (or an equivalence/noninferiority margin violation); an isolated negative point estimate is not sufficient. For mixed training, primary endpoints: equal-category macro average and worst-category score, accompanied by grounding noninferiority and hallucination/abstention rates. Keep unaveraged per-task results visible. Rule/metadata-only and no-image controls detect shortcut learning.

## Patient-cluster inference

Unit of independence is patient, with all longitudinal visits, acquisitions, slices, frames, and related questions kept together. If datasets have multiple sites/scanners and external transport matters, report site-stratified estimates or a site-held-out analysis. Aggregate question outcomes to patient-by-category first (predeclare weighting so patients with many QAs do not dominate), then paired patient bootstrap CIs for two model outputs on the same test patients. For between-source results, use hierarchical/source-stratified patient resampling; if sites are few, report per-site effects without overclaiming a population CI. For stochastic inference, use fixed prompt-level seeds or repeated decoding and nest that variance appropriately. Training seed variation is separate from test-set uncertainty; show both rather than hiding one in a pooled QA-level CI. Report absolute differences, interval, patient n, and missing/invalid output counts. Multi-comparison control or a predeclared small set of primary contrasts is needed across many transfer cells.

## Reward-scale and verifier controls

- Audit each reward's support/range, base-policy median and variance, zero-reward frequency, within-group ties, invalid-output frequency, advantage magnitude, gradient norm, update clipping, and category share of effective updates. A nominal `[0,1]` range alone does not balance learning signal.
- Test reward-router invariants on known real annotations: frame index and coordinate convention, box overlap, left-right flip, numeric tolerance, missing-reference behavior, and invalid JSON. Include adversarial candidate outputs: constant normal, abstain, generic anatomy text, guessed metadata, copied coordinates, and unsupported diagnosis. Reward cannot score reference labels that leak through the prompt.
- Important RL nuance: Vero's paper defines group-relative advantage `A=(r-mean_group)/(std_group+epsilon)`. For a group from one task, a *positive affine* rescaling of every rollout reward largely cancels (exactly when epsilon is negligible); therefore raw numeric scale may not itself change gradient priority. Nonlinear normalization, additive reward components, ties/zero variance, clipping, group composition, or downstream filters can change outcomes. Demonstrate the mechanism empirically rather than assuming scale imbalance from mixed reward ranges. MedGRPO uses a nonlinear median-centered transform, so reproduce that actual operation for a fair control.
- Freeze reward-calibration statistics on training/reference data only. Avoid adapting them on validation or BrainTRACE test outcomes. Separate a verifier's ability to score known annotations from its clinical validity; where judge rewards are unavoidable, use blinded independent human ratings of a sample and assess judge bias by pathology/severity and response style.

## Predeclared decision gates

**GO (empirical transfer study):** at least two (preferably three) authentic distinct tasks with independent patient splits and reliable verifiers; matched pretrained and RL comparisons run; off-diagonal transfer and worst-task metrics reported with patient-cluster uncertainty; no important grounding or hallucination regression. **GO (new method):** additionally, a distinct technical operation beats both Vero-style uniform sampling and a faithful MedGRPO-style reward control under matched compute/data, on independent patients and at least one external source, with plausible mechanism supported by ablation.

**REFORMULATE:** real data supports only 2D/multi-frame grounding and categorical QA, no trustworthy quantitative/longitudinal labels, or the only robust result is a careful MRI application/benchmark. Narrow to a defensible empirical evaluation rather than claim longitudinal RL or algorithmic novelty.

**KILL a scientific claim:** patient leakage or image-answer mismatch; test data/rubric used in training or model selection; rewards can be maximized by constant/abstain/metadata shortcut; no actual weight update or matched model inference; H1 off-diagonal deterioration absent or unreproducible; balanced mixture fails to beat strong mixture/reward controls; claimed gain disappears under independent-patient or source-held-out evaluation. These are claim-specific KILL rules; they need not end useful engineering work.
