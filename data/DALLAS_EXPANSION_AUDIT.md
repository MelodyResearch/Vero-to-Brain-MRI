# Dallas real-image cohort expansion audit

**Status, 2026-10-15:** Data-access and image-integrity work completed. Model inference, Vero/GSPO/MedGRPO training, longitudinal registration, segmentation, image quality grading, and clinical change inference were **not run**.

## Source and bounded selection

The source is the public [OpenNeuro Dallas Lifespan Brain Study ds004856 version 1.3.0](https://openneuro.org/datasets/ds004856/versions/1.3.0), with BIDS/annex metadata pinned at Git commit `077d0a4e4f32b7c18e3628893a96708ef24e1178` in the local metadata checkout. NIfTI payloads came from the corresponding public `openneuro.org` S3 objects. This extends the prior two-subject, eight-volume pilot by **10 additional subjects and 20 T1 MPRAGE volumes** (wave1 and wave2, documented `run-1` at each wave). No FLAIR files were added.

Selection was deterministic and bounded, not a probability sample. Of the metadata subjects, 292 met all pre-download filters: both run-1 T1 sidecars and annex links present; Philips listed at both waves; repetition and echo times within 3% across waves; positive MRI interval under 10 years; each annex file under 20 MB; and excluding the two existing pilot subjects. Among these, subjects were chosen greedily by closest wave1 MRI age to 22, 27, 32, 42, 52, 62, 67, 72, 82, and 89 years, with BIDS ID as a tie break. This creates age coverage for a feasibility audit; it does not produce a representative cohort, clinical stratification, or patient-independent train/test split. The selected wave1 ages span 22–89 years and recorded MRI intervals span 3.52–4.20 years.

## Directly verified image data

For all **20 newly downloaded** T1 files, actual byte size and SHA-256 exactly matched the pinned Git-annex key. Total new compressed payload is **144,373,664 bytes**. Each file loaded as a nonempty finite 3D NIfTI with a finite nonsingular affine. Each BIDS subject/session was linked to `participants.tsv`, and each sidecar stated Philips. All 10 pairs had matching 1.0-mm isotropic voxel spacing. Their native header shape was `256×256×160`, with native orientation `PSR`; the project loader reoriented all 20 to `160×256×256` in `RAS` without changing voxel spacing. New image sidecar repetition times span 0.008072–0.008299 s and echo times 0.00369–0.00384 s. Two sampled T1 volumes were rendered in axial and coronal views and visually inspected for anatomical plausibility; this was not a systematic expert QC of all 20. These checks establish byte integrity and basic geometry, **not** image quality, within-person anatomical alignment, or acquisition equivalence beyond recorded fields.

Together with the earlier pilot, local ignored storage now contains **12 distinct subjects, 24 subject-wave sessions, and 28 volumes**: 24 T1 MPRAGE and four FLAIR. The original four canonical T1 arrays were `160×256×256` at approximately 1-mm isotropic spacing; their raw array ordering can differ from the new native-header audit. Existing FLAIR arrays had three `512×512×64` volumes at approximately `0.449×0.449×2.5` mm and one `512×512×24` volume at approximately `0.449×0.449×6` mm. One existing FLAIR wave pair is therefore through-plane discordant. The **new T1 shape and spacing are constant**, so a shape/spacing-only shortcut baseline would be uninformative within that subset; header affine, intensity distribution, scanner details, and demographic metadata remain potential shortcuts and require explicit controls.

The exact subject list, paths, source hashes, acquisition values, affines, shapes, voxel ranges, and intervals are stored only in ignored `local_data/dallas_expansion_private_receipt.json`. Original pilot details are in ignored `local_data/ds004856_evidence/private_receipt.json`. Neither source images nor subject-level receipts belong in Git.

## Task and label assessment

The most immediately program-verifiable task supported by these 12 subjects is **same-person wave1↔wave2 scan linkage** using BIDS subject/session identity as the answer. It can exercise paired 3D image ingestion, negative pair construction, patient-disjoint splitting, and a verifier. It is a narrow technical task: a model may solve it through nonanatomical acquisition or affine cues, and success would not establish longitudinal brain reasoning. A credible first run must compare image input with no-image, metadata-only, header/geometry-only, intensity-summary, and visit-swapped controls. The 12-subject set is still too small for a meaningful held-out model estimate.

A second technically verifiable task is prediction of the **sign of a FreeSurfer-derived regional/global summary difference**, using the public derivative workbook as the reference. It remains a cross-sectional pipeline measurement with unknown test–retest uncertainty, possible segmentation errors, and no voxelwise reference mask. It cannot be called clinical progression, atrophy, or a biological ground truth solely because the numeric sign is available. Such prompts should only be used after defining a prespecified change threshold from repeatability data and checking source image/derivative provenance. Visit chronology is verifiable from `participants.tsv`, but can be answered from metadata alone and is not image-grounded.

The present files do **not** supply expert lesion masks, region boxes, adjudicated diagnoses, or validated within-person change labels. FLAIR lesion localization, causal interpretation, and change detection are therefore not yet program-verifiable at the standard needed for a strong Vero reward. Multitask uniform mixing might overrepresent easy linkage/metadata checks relative to hard anatomy; per-task eligibility, reward variance, prevalence, and cost should be measured before any balance claim.
